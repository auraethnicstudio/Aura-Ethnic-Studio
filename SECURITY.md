# Security Policy

## Supported version

Security fixes are applied to the current `main` branch and the live GitHub Pages storefront.

## Reporting a vulnerability

Please do not publish exploit details, customer information, order details, credentials, or payment information in a public GitHub issue.

Use the contact channel shown on the [Aura Ethnic Studio storefront](https://auraethnicstudio.github.io/Aura-Ethnic-Studio/store-x7m9q4v2k8/) and begin the message with **SECURITY REPORT**. Include the affected page, clear reproduction steps, expected impact, and a safe proof of concept that contains no real customer data.

Never send passwords, one-time codes, API keys, payment details, or private customer information.

## Scope

The storefront is a static client-side site. It has no server-side customer database, payment processor, account login, or administrative panel. GitHub Pages and third-party image delivery remain outside the repository's direct control.
