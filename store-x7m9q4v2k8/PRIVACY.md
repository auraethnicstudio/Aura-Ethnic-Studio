# Storefront Privacy Notes

The Aura Ethnic Studio storefront code does not include analytics, advertising trackers, fingerprinting, geolocation requests, or customer-IP storage. It does not set tracking cookies.

The shopping bag is stored only in the visitor's browser so their selection can survive navigation. Delivery details are sent only when the visitor chooses to continue the order through WhatsApp.

Like every public website, network providers involved in delivering the site—including GitHub Pages and external product-image CDNs—may receive technical request data such as an IP address. The storefront code cannot prevent infrastructure providers from processing that data for delivery and security.
